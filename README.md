# Market Move Radar (SALES-2)

A Workforce Solution demo for the Nestlé Vietnam AI Reinvention programme. It watches price, promo, pack and shelf moves across general trade, modern trade and eCom, compares them with history and Nestlé's own sales, and proposes response scenarios with impact and risk. People decide every response.

- How it is built, run and tested: [docs/MARKET_RADAR.md](docs/MARKET_RADAR.md)
